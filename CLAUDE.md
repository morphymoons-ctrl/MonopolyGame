# Монополия

Настольная «Монополия» для Windows (WPF, .NET 8) на 2–5 игроков. Каждый играет за своим ПК, подключение по сети: локальная сеть, Radmin VPN, ZeroTier, Tailscale. Тема — украинские бренды, валюта гривна.

Документация и общение — на русском. Комментарии в коде тоже на русском (так сложилось в проекте); имена в коде — на английском.

**Весь текст, который видит игрок, — на украинском**: интерфейс, журнал, сообщения движка и сети, названия клеток и карточек. Новый текст в игре тоже пишем сразу по-украински. Глаголы в журнале — в настоящем времени («купує», «платить»): у них нет рода, фраза подходит любому игроку.

## Документы

- [docs/RULES.md](docs/RULES.md) — правила игры, **источник истины для движка**. Пункты «❓ Решить» решает автор; без его ответа берётся «Предложение».
- [docs/PLAN.md](docs/PLAN.md) — этапы разработки и статус. После выполнения пункта — отметить его.

## Структура

| Путь | Что там |
|---|---|
| `src/Monopoly.Core/` | Правила и состояние игры. **Никакого WPF и сети** — только чистый C#, чтобы движок можно было тестировать и запускать на хосте. |
| `src/Monopoly.Net/` | Сеть: хост (ASP.NET Core + SignalR внутри приложения), клиент, лобби, поиск игр по UDP. Порт 7777. |
| `src/Monopoly.App/` | WPF-клиент, собирается в `Monopoly.exe`. Показывает состояние и отправляет действия; правила здесь не пишем. |
| `tests/Monopoly.Tests/` | Тесты xUnit для `Monopoly.Core` и `Monopoly.Net` (сетевые — через настоящий хост на 127.0.0.1). |
| `Directory.Build.props` | Общие настройки и **версия игры** (`<Version>`). Клиенты разных версий не должны играть вместе. |

## Команды

- Сборка: `dotnet build MonopolyGame.sln`
- Тесты: `dotnet test MonopolyGame.sln`
- Запуск: `dotnet run --project src/Monopoly.App`
- Сеть без друзей: запустить две копии, в первой «Создать игру», во второй подключиться к `127.0.0.1`.

## Правила работы

- Новое игровое правило: сначала в `docs/RULES.md`, потом в `Monopoly.Core` с тестом, потом в интерфейс.
- Состояние игры меняет только движок. Интерфейс и сеть вызывают его действия и показывают события.
- Случайность — только через генератор движка (с seed), не `new Random()` в разных местах.
- Перед коммитом — сборка без ошибок и зелёные тесты.
