# План разработки

Цель — обычное Windows-приложение: до 5 друзей за своими компьютерами играют по сети. Подключение — домашняя сеть, Radmin VPN, ZeroTier или Tailscale.

**Схема сети:** один игрок создаёт игру, и его приложение становится хостом (сервер + игрок). Остальные подключаются по IP или находят игру в списке. Правила выполняет только хост.

Сеть делаем сразу после базового движка, а не в конце: тогда каждое новое правило с первого дня работает по сети.
